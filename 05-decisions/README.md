# Decisioni

Decisioni che riguardano più progetti. Quelle di un solo progetto vanno in
`02-projects/<progetto>/decisions/`.

- **Nome del file:** `NNNN-titolo.md`, con il numero successivo all'ultimo usato in questa cartella.
- **Modello:** [`decision.md`](../07-templates/decision.md).
- **Stati:** una decisione nasce `proposed` e diventa `accepted` con una pull request. Non si riscrive:
  si sostituisce seguendo la [procedura](../01-company/policies/knowledge-governance.md#procedure).
